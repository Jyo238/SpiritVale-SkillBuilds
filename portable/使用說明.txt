============================================
 SpiritVale Build 切換（Skill Builds）
============================================

打王要補血、練功要輸出，換一次流派就得重點一次技能、
再把整排快捷鍵重擺一遍——洗完點快捷列還會整排消失。

本 Mod 讓你把「技能點＋能力點＋裝備／神器／魔導書＋快捷列」
（想要的話再加上「時裝／坐騎／寵物＋外觀」）
存成一個 Build，之後點兩下就全部換回來。

--------------------------------------------
【安裝】
--------------------------------------------
1. 把壓縮檔完整解壓縮到任意資料夾
2. 關閉遊戲，雙擊「一鍵安裝.bat」
3. 依畫面指示完成（會自動偵測遊戲位置；
   沒裝過 BepInEx 框架會自動下載安裝）

【重要】裝完後第一次開遊戲會多花 1~3 分鐘初始化，
畫面停住是正常的（已裝繁中翻譯包／其他 BepInEx Mod 者無此等待）。

--------------------------------------------
【使用方式】
--------------------------------------------
打開技能視窗，右上角會多一排 Build 按鈕。

  Shift + 左鍵 ... 把目前的配置「整組」存進這一組
                   （覆寫既有的要按兩次確認：它會用你身上的一切蓋掉那組）
  左鍵點兩次 ..... 還原這一組（第一次是確認，3 秒內再點一次）
  右鍵 ........... 編輯：改名、勾選要還原哪幾類、只更新時裝／外觀、刪除
  「＋」.......... 再加一組（最多 12 組）

熱鍵（不用開技能視窗也能用）：
  Ctrl + F1~F6 ......... 還原第 1~6 組（同樣按兩次確認）
  Ctrl+Shift + F1~F6 ... 儲存到第 1~6 組

還原時會依序做：套用點法 → 配能力點 → 換裝 → 時裝／外觀 → 綁快捷列，
畫面上會顯示每一步的進度。全程約十幾秒。

--------------------------------------------
【每組可以只換一部分】
--------------------------------------------
右鍵開編輯面板，九個勾選項可以各自開關：
  技能點 / 快捷列 / 能力點 / 裝備 / 神器 / 魔導書
  時裝（含坐騎／寵物） / 外觀（長相）
  卸下快照沒有的裝備／時裝欄

儲存時「永遠全部記下來」，勾選只決定還原時要動哪些，
所以隨時改主意都不用重存。

善用這點可以做出「只勾裝備」的純換裝組——
打王裝、練功裝、打錢裝一鍵切換，完全不碰點法與能力點；
或「只勾時裝＋外觀」的純造型組。
按鈕上顯示 * 就代表這組是部分還原。

時裝＝衣櫃裡套用的一切：外裝、武器外觀、坐騎、寵物、
光環／拖尾特效、稱號、徽章…只能套用衣櫃裡已擁有的。
外觀＝人物長相（膚色／髮型／髮色／眉／鬍／嘴／眼／眼色／耳／瞳）。

【注意】時裝與外觀「新 Build 預設不勾」——打扮通常是「人」的
不是「流派」的；預設勾上的話，存完 Build 之後換的坐騎、改的髮型
會在還原時被換回去。想每組各一套打扮，右鍵那組打勾即可
（不用重存，儲存時本來就全記）。

【注意】打勾只是開關，資料要「那一組」自己存過才有。
舊版存的 Build 沒有時裝／外觀資料（還原完成時會明講），
補資料不用整組重存：右鍵那組 →「把目前的時裝／外觀存進這組
（其他不動）」——技能／裝備／能力點一個都不會動。

【防手滑】Shift+左鍵是「整組覆寫」：會用你目前身上的技能／裝備／
打扮全部蓋掉那組，所以覆寫既有 Build 要按兩次確認。
典型事故：剛還原完 A、想幫 B 存個造型就 Shift+點 B → B 的點法
變成 A 的。只更新造型請用右鍵面板那顆按鈕。
被覆寫／刪除的舊 Build 會自動備份到同資料夾的
  local.spiritvale.skillbuilds.presets.backup.json
（每角色最近 30 筆）。要救回：關遊戲，把那筆的 Preset 貼回
presets.json 對應位置。

--------------------------------------------
【運作原理】
--------------------------------------------
全程呼叫遊戲自己的功能，不改任何數值：
  技能點 ....... 跟你在技能視窗右鍵退點、再按「套用」同一條路
  能力點 ....... 跟你在能力點視窗按 + 再套用同一條路（只加不減）
  換裝 ......... 跟你手動穿脫裝備同一條路
  時裝 ......... 跟你在衣櫃按「套用」同一條路（只能套已擁有的）
  外觀 ......... 跟你在衣櫃「外觀」頁籤／造型師 NPC 改長相同一條路
  快捷列 ....... 跟你手動拖技能上去同一條路

本 Mod 不會呼叫任何「重置」——重置技能／能力點是 Waybinder NPC
專屬的功能，應該由你自己去按。

伺服器端的檢查完全不變（點數不足、需求不符、物品不在背包，
一樣會被擋下），本 Mod 只是幫你把這些手動操作一次做完。
每一步都會確認伺服器真的接受了才做下一步，不是送出就當成功。

--------------------------------------------
【Build 存在哪裡 / 換電腦】
--------------------------------------------
Build 依「角色」分開存（同帳號不同角色互不干擾），
檔案預設在：
  <遊戲目錄>\BepInEx\config\local.spiritvale.skillbuilds.presets.json

換電腦時把這個檔案複製過去即可。
或者在設定檔填「存檔資料夾」指到雲端同步資料夾
（OneDrive／Google 雲端硬碟等），兩台電腦就會自動共用。
注意不要兩台同時開遊戲改 Build，雲端同步會打架。

--------------------------------------------
【設定】
--------------------------------------------
第一次啟動遊戲後，設定檔自動生成於：
  <遊戲目錄>\BepInEx\config\local.spiritvale.skillbuilds.cfg

可調整：Build 數量、熱鍵開關、按鈕列位置微調、存檔資料夾、
新組的預設勾選、診斷模式。

--------------------------------------------
【常見問題】
--------------------------------------------
Q: 可以跟「繁中翻譯包」「紫星販賣保護」「交易所比價」一起用嗎？
A: 可以，同為 BepInEx 外掛各自獨立。已裝過任一個的話，
   本安裝器會偵測到 BepInEx 已存在並直接沿用。

Q: 需要找 NPC 嗎？
A: 技能不用——本 Mod 送出的是「最終點法」，跟你右鍵退點再按套用
   完全同一條路，隨地都能用。

   能力點則要看情況：能力點只能加、不能減（遊戲介面就只有 +），
   減能力點的唯一途徑是 Waybinder NPC 的「Reset Attributes」。
   所以如果你要還原的 Build 需要「調降」某項能力點，
   本 Mod 會跳過能力點、把其他項目照常還原，並提示你
   先去 Waybinder 重置能力點，再還原一次即可。

   本 Mod 不會替你呼叫任何重置——那是 NPC 專屬的功能，
   應該由你自己去按。

Q: 還原完有幾件裝備沒穿上？
A: 畫面上會明確列出是哪幾件。常見原因是那件已經賣掉／交易掉，
   或等級與需求不符。本 Mod 會把能做的都做完再回報，
   不會做到一半停住。

Q: 為什麼在戰鬥中不能還原？
A: 伺服器本來就禁止戰鬥中換裝，所以會先擋下來，
   免得換到一半失敗留下半套配置。

Q: 舊版存的 Build 沒有裝備和能力點？
A: 對，那是舊版本存的快照。重新 Shift+左鍵存一次就會補上。
   舊快照還原時會自動跳過裝備與能力點，不會把你身上的東西卸掉。

Q: 從舊版升級上來，為什麼「能力點」還是打勾的？
A: 因為每一組 Build 的勾選是各自存的，不會被新版的預設值回頭改寫
   ——否則你手動打開過的設定會被靜默關掉，那更糟。
   新版預設不勾能力點（加下去就得跑一趟 NPC 才能重來），
   但既有的 Build 維持原樣。要關就右鍵那組 Build 取消勾選即可。

Q: 這個安裝包有毒嗎？
A: 無毒且可自查：所有腳本皆為明文（記事本打開就看得到），
   二進位檔只有 BepInEx（知名開源載入器）與本 Mod 的 DLL
   （原始碼公開在 GitHub）。安裝時的網路連線只用於下載
   BepInEx 官方框架；Mod 執行期間不連任何第三方伺服器、
   不蒐集任何資料。

Q: 會不會被 Ban？
A: 誠實說：線上遊戲使用第三方工具都有風險，請自行斟酌。
   可參考的事實：所有動作都走遊戲原生管道、與手動操作
   發出的請求完全相同、不改數值、不偽造封包、
   且本遊戲目前無反作弊程式。

   另外，2026/8/5 有玩家在 Discord 詢問官方對漢化包與詞條工具的
   立場，SPR 團隊回覆大意是「目前允許使用非官方工具，但官方不
   負責，帳號問題與資料遺失由玩家自行承擔」。

   請注意三點：那是即時問答不是正式公告，立場可能改變；
   被問到的是「不對伺服器多送東西」的顯示類工具，本 Mod 會實際
   送出換點與換裝的請求，性質不完全相同；以及官方明講
   「資料遺失自負」——所以本 Mod 的設計刻意讓每一步都可獨立失敗
   而不破壞現況（技能是整包接受或整包拒絕，失敗時你原本的點法
   完全不會被動到）。

Q: 按鈕列位置擋到東西？
A: 設定檔裡的「按鈕列水平微調」「按鈕列垂直微調」可以挪，
   往左／往下填負數。改完切出遊戲再切回來就生效。

Q: 出問題怎麼辦？
A: 雙擊「產生診斷報告.bat」，把桌面上生成的報告貼到回報串。
